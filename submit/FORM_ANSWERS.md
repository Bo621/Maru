## [6/12] 프로젝트 한 줄 요약 (50자)

```
팔로우한 사람의 사전 판단과 실제 결과를 함께 보는 소셜 피드
```

> **1차 초안은 「결과를 알기 전에 고정한 판단이 맞았는지까지 보이는 소셜 피드」였다.**

> **「POI 뒤에 소셜 피드만 붙였다」로 읽힌다**는 지적을 받았고, 동의해서 바꿨다.

바뀐 문장은 **소비 행위를 앞에 둔다** — 팔로우하고, 피드를 보고, 결과를 확인한다.
Track 02 는 CONSUMER/SOCIAL 트랙이다. 프로토콜이 아니라 쓰는 사람이 먼저 보여야 한다.

「사전 판단」이 「결과를 알기 전에 고정했다」를 대신한다. 짧고, 뜻이 같다.

   마루는 백엔드가 없고 EIP-1193만 요구합니다. 지갑 안에서 「내가 팔로우한 사람의

   현재 「도장 검증 — TESTNET FAUCET」 라벨을 노출합니다. 소비자 화면에서 도장
   표기를 어디까지 허용하는지 가이드에 따르겠습니다.

3. 커뮤니티 접점
   실사용자 검증이 남았습니다. 지금 피드의 기록은 데모 페르소나입니다. 반복 발행
   의향을 검증할 사용자 접점이 필요합니다.

   화면이 업비트 1분봉으로 관측값을 다시 계산하고 「화면 재계산」이라 밝힙니다.
   소비자 화면의 출처·확정성 표기 기준이 있으면 따르겠습니다.

5. 월렛 안의 정보 구조와 반복 발행 UX를 검토할 소비자 제품 멘토링을 받고 싶습니다.

## [12/12] GIWA 팀에 전하고 싶은 메시지 (500자)

```
마루의 주장은 「우리를 믿어라」가 아니라 「직접 확인하라」입니다.

공개 URL에서 지갑 없이 확인됩니다. 결과를 알기 전에 고정된 판단이 흐르고, 데모
피드에는 화면 재계산상 맞음과 틀림이 함께 보입니다. 이유 원문은 해시가 온체인
커밋과 일치할 때만 인용으로 보입니다. 활성 정산 11건의 등록 관측값은 POI verifier
CLI 재계산과 모두 MATCH였습니다. 예측 적중 수가 아닙니다.

한계도 분명합니다. 피드의 기록은 시연용 데모 페르소나이고 실사용자는 없습니다.
팔로우는 브라우저 로컬 저장이지 온체인이 아닙니다. 화면에 그렇게 적어 두었습니다.

GIWA의 낮은 발행 비용과 월렛 환경에서 확인하려는 가설이 있습니다. 판단 하나를
올리는 비용이 원 단위일 때, 사람들이 틀릴 수도 있는 판단을 공개적으로 고정하는가
입니다.

성공 기준은 30일 안에 사용자 10명이 각 3건 이상 발행하는 것입니다. 아직 달성
여부를 확인하지 않은 목표이고, 실적으로 쓰지 않습니다.
```
