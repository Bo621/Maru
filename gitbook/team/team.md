## 왜 이 사람이 이 제품을 만드나

마루는 **「결과를 알기 전에 고정된 판단만 흐르는 피드」**입니다.
제 커리어가 이 문장의 두 부분에 각각 걸립니다.

| 해온 일 | 마루에서 대응하는 것 |
|---|---|
| 펀드 기준가·지수 산출 로직 설계 (펀드평가사) | 「무엇을 기준으로 맞았다고 하는가」를 화면이 아니라 **[미리 고정된 조건](../design/verdict.md)**으로 정한다 |
| 운용 성과 정산·손익 검수 0→1 (가상자산 전략상품) | 판정을 발행자가 아니라 **[화면이 업비트 1분봉으로 재계산](../design/verdict.md)**해 붙인다 |
| 거래소 이상거래 탐지 0→1 | 「맞은 것만 골라 보여주는」 선택적 공개를 [설계 단계에서 막는다](../problem/what-is-proven.md) |
| 여러 거래소 자산을 한 화면에 모으는 서비스 운영 (베스탯) | **흩어진 기록을 한 줄로 모아 보여주는** 소비자 화면을 만드는 일 자체 |

앞의 셋은 「기준을 누가 정하고 누가 검증하는가」였습니다. 마지막 하나가 다릅니다 —
**흩어진 것을 사람이 읽을 수 있게 모으는 일**이고, 마루는 그쪽에 더 가깝습니다.

> 증명 레이어를 만드는 일은 [POI](https://vestat.gitbook.io/poi/)에서 하고 있습니다.
> 마루는 그 위에 **사람이 보는 표면**만 얹습니다.

## 주요 경력

**베스탯 (VESTAT)** · 2024.05 ~ 현재
여러 거래소에 흩어진 자산을 한 화면에서 보고 정기 리포트를 받는 서비스.
6개 거래소 API 연동, 문제 정의부터 운영까지 1인 E2E.
국책 R&D(창업성장기술개발 디딤돌) 1.2억 규모 선정 · 수행 완료.

**가상자산 전략상품 플랫폼**
누적 투자금 $4M · 트레이딩 볼륨 $500M.
기준가 생성 → 정산 → 검수 → 리포트를 하나의 제품 프로세스로 통합(0→1).

**NFT 경매 플랫폼**
스마트 컨트랙트 기반 경매 플랫폼 기획·운영 총괄.
낙찰 대금 분배·로열티 배분 규칙을 온체인 확정 기준으로 정의.

**가상자산 로보어드바이저** — 출시 6개월 운용자산 10억

**가상자산 거래소** — 오픈 초기 운영 · FDS 0→1

**펀드평가사** — 펀드 기준가 · 지수 · 리스크 지표 산출

## 1인이 어떻게 이만큼 만들었나

AI 개발 체계를 제품처럼 운영합니다.

| 단계 | 무엇을 |
|---|---|
| 기획 | PRD · 화면설계서 · 수용 기준을 **먼저 문서로 확정** |
| 구현 | Claude Code |
| 리뷰 | Codex로 교차 검증 — **구현자와 리뷰어를 분리한다** |
| 검증 | 테스트를 게이트로 두고, 통과하지 못하면 병합하지 않는다 |

이 체계가 마루 개발 중 실제로 잡아낸 것들입니다.

| 잡은 것 | 무엇이었나 |
|---|---|
| 이름이 주장보다 넓은 테스트 | 「검증을 통과한 원문**에만** 표시가 붙는다」인데 단언은 양성 경로만 봤다. 변조 원문이 그대로 실려도 통과했을 것 |
| 영구히 판정 불가한 결정 | 24시간 관측 구간이 업비트 1회 조회 한도(200분)를 넘어 다시 시도조차 못 하는 상태로 굳었다 |
| 사실과 다른 비교표 | 「POI에는 사람이 읽는 화면이 없다」고 적었는데 [실제로는 있다](https://vestat.gitbook.io/poi/usage/screens) |

세 건 다 **사람이 읽어서** 잡은 것이 아니라 **교차 검증이** 잡았습니다.
자세한 내용은 [하지 못한 것](../limits/not-done.md)에 있습니다.
