# 용어

이 문서에 나오는 말을 한 줄씩 풀었습니다. 정확한 정의보다 **처음 읽을 때 막히지 않는 것**을
목표로 썼습니다. 프로토콜 쪽 정의가 더 필요하면 [POI 백서의 용어집](https://vestat.gitbook.io/poi)을 보세요.

## 이 화면에서 자주 보이는 말

| 말 | 뜻 |
|---|---|
| 결정 | 판단 한 건. 「무엇을 볼지」와 「어떻게 되리라 보는지」를 결과가 나오기 전에 못 박아 온체인에 올린 것 |
| 관측 구간 | 맞았는지 따질 때 쓸 시각 범위. **온체인은 초 단위로 기록합니다.** 분 경계로 정렬하는 것은 마루의 작성 화면이 붙인 규칙일 뿐입니다. 올린 뒤에는 바꿀 수 없습니다 |
| 커밋 | 원문·salt·용도·체인·발행자를 묶어 만든 해시를 먼저 온체인에 올려 두는 것입니다. 나중에 원문과 salt를 공개하면 누구나 대조할 수 있습니다 |
| 이유 원문 | 그때 왜 그렇게 봤는지 적은 글. 커밋해 둔 해시와 맞을 때만 화면에 인용으로 보입니다 |
| 정산 | 관측 구간이 끝난 뒤 발행자가 결과값을 온체인에 올리는 것 |
| 활성 정산 | 올린 뒤 철회되지 않고 살아 있는 정산 |
| 판정 | 이 화면이 업비트 1분봉으로 다시 계산한 맞음·틀림. **온체인에 기록된 값이 아닙니다** |
| 도장 | 도장(Dojang)의 Verified Address 스냅샷입니다. 결정 시점에 그 주소가 허용된 발급자의 유효한 기록을 갖고 있었다는 뜻이고, 항상 발급자 라벨과 함께 봐야 합니다. 지금 데모 데이터의 발급자는 `TESTNET FAUCET`이라 KYC나 신원확인으로 일반화할 수 없습니다 |
| 입장 변경 이력 | 같은 지갑이 앞서 올린 판단을 가리켜 두는 것. 생각이 바뀐 자취가 남습니다 |
| 프로토콜 시연 | POI 가 컨트랙트 상태를 보여주려고 올린 기록. 시세 판단이 아니라서 배지로 구분합니다 |
| 발행자 | 결정을 올린 지갑 |

## 상태

관측 구간이 어디까지 왔는지, 결과가 올라왔는지에 따라 카드에 찍힙니다.

| 상태 | 뜻 |
|---|---|
| 해당없음 | 예상 결과가 없는 결정입니다. 맞고 틀림을 따지지 않습니다 |
| 대기 | 관측 구간이 아직 시작되지 않았습니다 |
| 관측중 | 구간이 진행 중입니다 |
| 등록대기 | 구간은 끝났고 결과 등록을 기다리는 중입니다 |
| 기한초과 | 올려야 할 기한이 지났는데 안 올렸습니다. **숨기지 않고 그대로 보여줍니다** |
| 등록완료 | 결과가 올라왔습니다 |
| 지연등록 | 기한이 지난 뒤에 결과가 올라왔습니다 |

## 체인 쪽 말

| 말 | 뜻 |
|---|---|
| EAS | Ethereum Attestation Service. 스키마에 따른 어테스테이션을 발행·조회·철회하는 프로토콜과 온체인 컨트랙트입니다 |
| 어테스테이션 | EAS가 스키마·시각·발행자·수신자·데이터를 묶어 저장하는 UID 기록 한 건 |
| 스키마 | 그 기록이 어떤 항목을 담는지 정한 틀 |
| 리졸버 | 기록이 올라올 때 규칙을 검사하는 컨트랙트. 규칙을 어기면 거래가 되돌아갑니다 |
| UID | 어테스테이션 한 건의 고유 번호 |
| 해시 | 어떤 값을 고정 길이 문자열로 바꾸는 계산. 원본이 조금만 달라도 결과가 완전히 달라지고, 결과에서 원본을 되돌릴 수 없습니다 |
| salt | 커밋을 만들 때 섞는 난수. 추측을 어렵게 하려고 섞는 값이고, 충분히 무작위여야 효과가 있습니다 |

| 탭 | 피드를 거르는 세 갈래: 전체 · 팔로우 · 곧 결과 나옴 |
