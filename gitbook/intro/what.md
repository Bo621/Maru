# 무엇을 하는 제품인가

마루는 GIWA Sepolia에 있는 POI 결정 기록을 읽어 보여주는 **읽기 전용 소비자 화면**이다.
쓰기(판단 발행)만 지갑이 필요하고, 나머지는 전부 지갑 없이 된다.

```
피드                프로필                발행자별 기록
#/feed         →    #/p/<address>   →     같은 지갑의 결정만 시간순
결정 목록            누르면 이동            승률·집계는 없다

결정 상세            검증
#/d/<uid>      →    #/verify/<uid>
조건·정산 상태        POI verifier로 재계산 안내
```

## 피드가 보여주는 것

여러 지갑의 결정을 시간 역순으로 나열한다. 각 줄에 상태(대기·관측중·등록완료·
기한초과), 발행자, 조건 문장, 관측 구간(UTC)이 있다. 도장 검증 스냅샷이 있으면
라벨이 붙고, 없으면 그 조각을 아예 그리지 않는다 — 「미검증」이라고 낙인찍지 않는다.

## 필터가 하는 일과 하지 않는 일

두 조건으로 거른다 — **도장 검증 지갑만**, **발행자별 활성 정산 최소 건수**.
둘 다 URL 쿼리에 실려 링크로 공유된다(`?verified=1&match=2`).

`match`는 공유 링크 호환을 위한 파라미터 이름이다. **실제로 거르는 값은
MATCH 판정 수가 아니라 활성 정산이 존재하는 결정 수다.** 정산 등록은 관측값
일치를 보장하지 않는다 — 걸러진 결과를 봐도 각 판단은 직접 검증해야 한다.

## 판정이 하는 일과 하지 않는 일

관측이 끝난 결정에는 업비트 1분봉으로 다시 계산한 맞음·틀림이 붙는다.
**이 판정은 화면이 재계산한 것이지 온체인 기록이 아니다.** 틀린 것을 숨기지
않는다. 자세한 규칙은 [맞고 틀림 — 업비트 재계산](../design/verdict.md)에 있다.

## 세 화면 + 결정 상세

피드 · 프로필 · 결정 상세 · 검증 넷이 전부다. 판단 발행(`#/write`)은 지갑이
있을 때만 쓸 수 있고, 없으면 연결 안내가 뜬다 — 막다른 길을 만들지 않는다.
